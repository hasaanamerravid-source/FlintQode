Requirements

  • Node.js 20 or newer
  • Rust stable (rustup)
  • Linux: WebKitGTK 4.1 and GTK 3 development packages
  • Windows: WebView2 and the MSVC build tools
  • macOS: Xcode command line tools

Clone the repo, run npm install && npm run build:app.
