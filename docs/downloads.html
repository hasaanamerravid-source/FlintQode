Install

Get it running

One command on most Linux distributions, a plain installer on Windows, or a disk image on macOS.

Debian / Ubuntu

Install the .deb with APT and let it pull the runtime dependencies.

sudo apt install ./FlintQode_1.4.3_amd64.deb

Fedora / openSUSE

Install the RPM through the native package manager.

sudo dnf install ./FlintQode-1.4.3-1.x86_64.rpm

Any Linux · AppImage

Download the AppImage, mark it executable and run it.

chmod +x FlintQode_1.4.3_amd64.AppImage && ./FlintQode_1.4.3_amd64.AppImage

Windows

Run the NSIS .exe installer or the .msi.

Both installers are self-contained and install to the usual Program Files location.

macOS

Open the .dmg and drag FlintQode into the Applications folder.

The build is unsigned; the first launch may need the usual Open Anyway step in System Settings.

Build from source

Requirements

What you need to compile FlintQode yourself.

  • Node.js 20 or newer
  • Rust stable (rustup)
  • Linux: WebKitGTK 4.1 and GTK 3 development packages
  • Windows: WebView2 and the MSVC build tools
  • macOS: Xcode command line tools

Clone the repo, run npm install && npm run build:app.
