What's new in FlintQode 1.4.5

Released 2026-11-24 · build 76.

Highlights

  • SolidJS 2 renderer. The whole interface is now compiled Solid 2 with fine-grained signals and Vite 8.
  • Aurora Slate design. A single design system refreshes the shell, menus, tabs, panels, editor, dialogs and status bar in dark and light themes.
  • Full editor typography and colour customisation, applied live and saved automatically.
  • Real PTY terminal with tabs, resize and interactive programs.
  • Git integration: branch in the status bar, diff gutter markers, blame, commit, stage.
  • Multi-root workspace, LSP tools, crash recovery, autosave and Markdown preview.

Fixes

  • Run File now saves first and reports backend errors in the Run panel.
  • Atomic writes, canonicalised paths, quoted Windows paths, reported shell errors.
  • Markdown preview never falls back to unsanitised HTML; window.open uses noopener.
  • Three-button Save / Discard / Cancel dialog for unsaved tabs.
  • Solid 2 lifecycle edge cases in menus, tabs, split editors and the status bar are resolved.

Website and installers

  • Fresh screenshots captured from the new interface; every page now describes SolidJS 2.
  • Version-aware download links, corrected macOS installer URL and full OS installer coverage for Linux, Windows and macOS.
  • CI builds with Node 22.12 to match the renderer toolchain.
