What's new in FlintQode 1.5.1

Released 2026-11-26.

Fixed in this release

  • Typing in large files is fast again. The editor no longer copies the whole document for every character, writes tab content back on a 400 ms debounce, and skips the global store update when a tab is already marked dirty. In the 1 MB HTML fixture, the full-document copy that used to run on each edit measured 0.43–1.87 ms; the incremental statistics path now takes about 4 µs.
  • Tab switches keep each file to itself. The outgoing editor is no longer fed the incoming tab's text during the switch, so a teardown cannot save one file's content into another.
  • The git gutter waits for a pause. Native git diff calls are debounced by 600 ms, stale replies are ignored, and the process no longer blocks the window.
  • Open File lists files again. An “All Files” (*) filter is passed to the native picker as no filter, instead of as an extension that some Linux dialogs read as “folders only”.
  • Less repeated work. Language servers get didOpen once per document, the diagnostics dedupe key no longer contains the whole file, and no-op store updates skip listeners and reactive version bumps.

Native work moved off the main thread

  • File read, write, search and directory listing, git history and diff commands, settings and session persistence, and terminal/shell launching now run on blocking worker threads. The window keeps painting while they finish.

Verification

  • Regression tests cover tab-switch content isolation, no-op dirty flags, LSP didOpen, the All Files dialog filter and the diagnostics dedupe key. The full frontend gate, the Rust test suite and the production build pass.
