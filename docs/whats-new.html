What's new in FlintQode 1.4.5

Released 2026-11-22 · build 62.

Highlights

  • Full editor typography and colour customisation, applied live and saved automatically.
  • Real PTY terminal with tabs, resize and interactive programs.
  • Git integration: branch in the status bar, diff gutter markers, blame, commit, stage.
  • Multi-root workspace: open several folders in one window.
  • LSP tools: signature help, hover docs, rename, code actions, workspace symbols.
  • Crash recovery and autosave keep unsaved buffers alive across restarts.

Fixes

  • Run File now saves first and reports backend errors in the Run panel.
  • Atomic writes, canonicalised paths, quoted Windows paths, reported shell errors.
  • Markdown preview never falls back to unsanitised HTML; window.open uses noopener.
  • Three-button Save / Discard / Cancel dialog for unsaved tabs.
  • Watchers emit the subscribed path; window maximize follows the resize event.

Website

  • Version-aware download links, macOS installer, SEO, sitemap, favicon, noscript.
  • Premium typography, animated background, and a Built-with page.
