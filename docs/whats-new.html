What's new in FlintQode 1.5.0

Released 2026-11-24.

New in this release

  • Line-length diagnostics are opt-in. The 120-character warning no longer appears by default. Enable it in Settings with your own limit and per-language overrides; disabling it clears its problems immediately. The Problems severity filter is reactive and does not rescan the document.
  • Terminals survive a hidden panel. Sessions stay alive when you hide the panel, closing one tab kills only its shell, and app exit stops every PTY. Set terminal.closeOnPanelHide to restore the old behaviour.
  • Verifiable updates. The website and in-app updater use a generated Pages manifest with exact tag-qualified URLs and SHA-256 digests. Downloads are verified before install, transient failures are retried, and partial files are cleaned up.

Performance

  • Editor statistics update with incremental deltas after an edit instead of recounting the document. Native search compiles glob patterns once, precomputes line starts and prepares replacements in parallel.
  • ADR 0006 records why no Java or C++ runtime was added: Rust already owns the native hot paths, and the remaining renderer work belongs to CodeMirror and SolidJS.

Carried over from 1.4.7

  • A responsive update button, a quieter Problems panel and one integrated terminal that starts in the workspace folder.
  • VS Code-style Extensions view with search, details, install, uninstall, enable, disable and local install from a plugin file.
  • Power save mode, interface scale, a minimal toolbar and editable code token colours.

Website

  • The Stats tab shows visitors, clones and installer downloads, refreshed from GitHub nightly and after each release.
  • Download links, release notes and installers now describe v1.5.0, with full OS installer coverage for Linux, Windows and macOS.
